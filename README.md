# Петька и Числоград

Обучающая 2D-адвенчура для детей 6+. Прототип первой главы «Часовая площадь».

## Стек

| Слой | Технология |
|---|---|
| Клиент | HTML + CSS + JavaScript (ES-модули), отрисовка через Canvas 2D API, без игровых движков |
| Шрифт | Comfortaa (округлый, с кириллицей), зашит в проект как woff2 |
| Анимации UI | Transitions.dev: resize, shimmer, stream - в CSS и в порте на канвас |
| Сервер | Python 3.11, FastAPI + Uvicorn |
| Данные | SQLite (прогресс), JSON (содержание глав) |
| Окно приложения | pywebview / WebView2 — в релизной сборке |
| Сборка | PyInstaller, один портативный exe |

## Запуск в разработке

Двойным щелчком:

```
start.bat
```

Скрипт сам создаст `.venv`, поставит зависимости, поднимет сервер и откроет браузер.

Вручную:

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m uvicorn server.app:app --host 127.0.0.1 --port 6244 --reload
```

Открыть: **http://127.0.0.1:6244**

## Управление

### Уровень чтения

При первом запуске игра спрашивает «Как ты читаешь?» - по слогам, немного или
хорошо. От ответа зависит длина текстов: во вступлении, в диалогах, в задачах.
Тот же выбор включает или выключает чтение по слогам. Поменять можно в меню,
кнопка «Читаю: …».

### Вступление

Перед игрой листается вступление: история, знакомство с героями, страницы про
цифры и про управление. Две кнопки сверху:

| Кнопка | Что делает |
|---|---|
| «Пропустить» | сразу в игру, минуя вступление |
| «По слогам» | весь текст игры печатается слогами: «чис-ло-град». Игре 6+, дети только учатся читать. Переключается ещё и в меню, выбор запоминается |

### Управление

| Действие | Клавиши | На планшете |
|---|---|---|
| Идти | ← → или A D | стрелки слева внизу |
| Прыжок | ↑ или W | кнопка со стрелкой вверх справа |
| Поговорить, решить задачу у ящика | Пробел (когда рядом появилась подсказка) | кнопка «Говорить» / «Решить» |
| Выбор темы / ответа | 1, 2, 3 или клик мышью | касание |
| Подтвердить / дальше | Пробел, Enter, клик мышью | касание |
| Поставить цифру в трафарет | перетащить мышью, щёлкнуть по трафарету или 1, 2, 3 | перетащить пальцем или коснуться трафарета |
| Ответить в задаче | клик по ответу или 1, 2, 3 | касание |
| Подсказка | кнопка «Помощь» | та же |
| Назад, закрыть | Esc | кнопки «Потом», «Назад», «Закрыть» |
| К главам | кнопка «Главы» или Esc | кнопка «Главы» |

Экранные кнопки появляются после первого касания экрана. Игра альбомная: в
портрете показывается просьба повернуть устройство. В меню есть «На весь
экран» (кроме iPhone: Safari там полный экран не даёт).

### Главы и монетки

«Играть» открывает выбор главы. Каждая глава - своя история со своей темой:

| Глава | Жанр | Учит | Цена |
|---|---|---|---|
| 1. Часовая площадь | рассказ | цифры 0-7, сложение | открыта |
| 2. Пекарня на углу | сказка | счёт до 9, вычитание | 60 монет |
| 3. Библиотека совы | рассказ | буквы и слова | 120 монет |
| 4. Погоня за Кляксой | история с выбором | всё вместе | 200 монет |

Монетки дают за каждую цифру, решённый ящик, задачу собеседника и финал
главы, а также за круги в «Заданиях» - тренировке вне сюжета. Тратятся
только на открытие глав. «Продолжить» возвращает в начатую главу с
сохранёнными цифрами и ящиками. Прогресс хранится в браузере и на сервере
(`petka_save.sqlite`).

### Звук

Музыка - восемь CC0-дорожек с OpenGameArt (см. `web/assets/audio/CREDITS.md`),
по одной на экран. Звуки кнопок, монеток, прыжка и ответов синтезируются
Web Audio. Музыка и звуки выключаются в меню отдельно.

## Редактор уровней

Открывается по адресу **http://127.0.0.1:6244/editor** (работает и
`/редактор`). Отдельная страница для разработки: главы правятся мышью, а не
руками в JSON.

Две проекции одного уровня сразу:

* **вид сбоку** - то же, что видит игрок: небо, дальний план, декорации по
  слоям, земля, цифры, ящики, собеседники, враги и передний план. Плюс линия
  пола, границы уровня, рамка видимого экрана и точка старта героя;
* **вид сверху** - глубина сцены: полосы планов от дальнего к переднему.
  Перетаскивание объекта вверх-вниз переносит его между планами, вправо-влево
  двигает вдоль улицы. Номер в значке - позиция в слое, то есть порядок
  отрисовки.

Панель справа правит свойства выделенного: кадр (список с миниатюрами и
поиском), координаты, размер, отражение, план. У цифр свои поля, у ящиков -
задача всех трёх видов с выбором верного ответа, у собеседников - весь
диалог, у врагов - участок патруля и скорости. Любое текстовое поле умеет
развилку по уровню чтения. Слева палитра всех кадров атласа: перетаскиванием
на сцену создаётся новый объект.

Перед сохранением глава проверяется теми же правилами, что и
`tools/check_chapter.py`: ошибки блокируют запись и показываются списком.

| Действие | Клавиши |
|---|---|
| Сохранить главу | Ctrl+S |
| Отменить / повторить | Ctrl+Z / Ctrl+Shift+Z |
| Копия объекта | Ctrl+D |
| Удалить | Del |
| Сдвиг на 1 (Shift — 10) | стрелки |
| Порядок в слое | PgUp / PgDn |
| Отразить | F |
| Линии и сетка | G |
| Снять выделение | Esc |
| Зум / прокрутка | колесо / Shift+колесо |
| Панорама | пробел или средняя кнопка |

### Редактор сцены в игре (режим отладки)

Простой предшественник: работает прямо в игре, только двигает существующие
объекты.

| Действие | Клавиши |
|---|---|
| Включить / выключить | F2 |
| Двигать объект | зажать ЛКМ и тянуть |
| Точный сдвиг | стрелки (Shift — шаг 10) |
| Масштаб объекта | [ и ] |
| Отразить по горизонтали | F |
| Сетка и линия пола | G |
| Двигать камеру | A / D |
| Сохранить главу на диск | Ctrl+S |

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/health` | проверка живости |
| GET | `/editor` | страница редактора уровней (алиас `/редактор`) |
| GET | `/api/chapters` | список глав для экрана выбора: номер, название, жанр, цена, иконка |
| GET | `/api/content/{name}` | сценарий и данные главы |
| POST | `/api/content/{name}` | сохранение главы из редактора (только в разработке) |
| GET | `/api/progress` | текущий прогресс |
| POST | `/api/progress` | сохранить прогресс |

## Сборка портативного exe

```bat
pip install pyinstaller
pyinstaller --noconfirm --onefile --noconsole ^
  --name "PetkaChislograd" ^
  --add-data "web;web" ^
  --add-data "server/content;server/content" ^
  run_desktop.py
```

Файл сохранений (`petka_save.sqlite`) создаётся рядом с exe, поэтому приложение
остаётся портативным: копируется на флешку и запускается без установки.
